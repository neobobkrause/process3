## 2. The files, in reading order

1. `01_neutral_terms.md`: a table of harness-neutral terms. For each, the Claude Code construct the sixth draft uses, the Codex construct, and whether the Codex entry is measured, documented, proposed or unknown.
2. `02_rules_one_harness_keeps.md`: every rule found that only one harness can keep as written, or that rests on something one harness lacks or has not been shown to have.
3. `03_codex_maximums_figures.md`: every figure found that bears on the four blanks, with its label and source, and where the repository's files disagree.
4. `04_codex_maximums_recommendation.md`: which figure the worker would put in each blank and why, and what is not known.

Each file is under 16,000 bytes, so each can be read in one read.
